# Amazon price scanner – Home Assistant add-on

Home Assistant add-on that runs a precise Amazon price scanner (IT/FR/ES/DE/UK/US → Israel) from your
home network and reports to a private Cloudflare Worker dashboard. It contains no credentials; the
Worker address and upload key are entered in the add-on configuration.

Install: Settings → Add-ons → Add-on Store → ⋮ → Repositories → add this repository URL → install
**Amazon Price Scanner**.
